# Zero to Millionaire: контекст для Claude Code

Idle-игра в одном HTML-файле. Слот внизу крутит месяцы жизни (1 спин = 1 месяц), наверху сцена с домом и персонажем. Старт в 18 лет с $0, цель — $1 000 000 до 65.

Автор — Руслан, соло-разработчик. Отвечай по-русски, коротко и по шагам, без воды.

## Команды

```bash
npm run build        # собрать dist/zero-to-millionaire.html (зависимостей нет)
npm test             # сквозные проверки в браузере, около 2 минут
npm run test:all     # e2e + крайние случаи + все развилки + фаззинг логики
npm run test:monkey  # случайные нажатия по интерфейсу
npm run test:sweep   # замер сдвигов вёрстки за целую жизнь
```

Тестам нужен Playwright: `npm install`, затем один раз `npx playwright install chromium`.

Браузерные тесты гоняют собранный `dist/`, не `src/`. Отдельный набор без пересборки (после `npm run build`):
`node tests/forks.js dist/zero-to-millionaire.html --print` (с `--print` печатает текст золотых вариантов), `node tests/monkey.js dist/zero-to-millionaire.html 20` (второй аргумент — секунды). Фаззинг логики идёт в Node без браузера: `node tests/fuzz-core.js 100 --rich`. Фильтра по отдельному тесту внутри `e2e.js` нет. `test:all` не включает monkey и sweep.

Симулятор баланса медленный, запускай по одной стратегии:
`ONLY=casual N=150 node tools/sim.js` (стратегии: afk, lazy, nofocus, casual, smart, casual+ad, smart+ad, allgold; `L=0|1|2` уровень наследия; `STAY=1` играть до 65).
Ещё в `tools/`: `feasibility.js` — достижимы ли трудные цели; `screenshots.js <html> <папка>` — снимки телефона и десктопа.

Git: ветка `main`, remote нет. В папке могут одновременно работать несколько сессий: чужие незакоммиченные правки не трогай, в коммит добавляй только свои файлы.

## Архитектура

| Файл | Роль |
|---|---|
| `src/core.js` | Вся логика, без DOM. Экспортирует `Core`. Работает в браузере и в Node |
| `src/art.js` | Рисунки сцены: дома, транспорт, персонаж. Только SVG-строки |
| `src/ui.js` | Интерфейс: слот, окна, меню, покупки, сохранение |
| `src/template.html` | Разметка с метками `/*FONTS*/ /*CSS*/ /*CORE*/ /*UI*/` |
| `src/style.css` | Стили. Телефон по умолчанию, десктоп от 920px |
| `scripts/build.js` | Склеивает всё в один HTML, шрифты вшивает как base64 |

Результат сборки — один файл без сетевых запросов. Это требование, не меняй.

## Правила, которые нельзя ломать

1. **Логика только в `core.js`.** Интерфейс не считает деньги и шансы сам, он вызывает `Core`.
2. **Версия состояния.** Сейчас `v: 6`. Любое новое поле состояния = новая ветка в `Core.migrate` и проверка в `validState` (`ui.js`). Ключ сохранения `zero-to-millionaire-v2` не менять.
3. **Никаких рывков вёрстки.** Строки покупок фиксированной высоты, место под изменяемый текст зарезервировано. После правок вёрстки запускай `npm run test:sweep`: по вертикали не должно сдвигаться ничего, кроме содержимого окон.
4. **Честный дизайн** (подробно в `docs/DESIGN.md`):
   - шансы видимы и одинаковы для всех, считаются точно в `Core.analyze`;
   - никакого «почти выпало»: пролетающие символы берутся из той же колоды, множитель не крутится в пустой месяц;
   - никаких офферов и рекламы на экране проигрыша;
   - никакого фальшивого дефицита, давления на отказ и трудного выхода;
   - реклама только по желанию игрока, на кнопке написано, что именно он получит.
5. **Не писать** «дофаминовая механика», «аддиктивный» как похвалу, «нейрохак». Утверждение «работает из-за психологии» либо с источником, либо с пометкой `[UNSUPPORTED]`.
6. **После каждой правки:** `npm run build`, затем `npm test`. Сборка сама останавливается на синтаксической ошибке.

## Как добавить типовые вещи

- **Развилку:** запись в `FORKS` (`core.js`): `ages`, `once`, `ok(s)`, `make(s)` с вариантами `a` и `b`. Золотой вариант строится сам; свой — через `gold(s)`, отключить — `noGold: true`. Проверка: `npm run test:forks`.
- **Улучшение слота:** `UPGRADES` в `core.js`, строка `li[data-kind="up-…"]` в шаблоне, текст в `UP_TEXT` (`ui.js`).
- **Наследие:** `PERKS` в `core.js`, применение в `newState`, строка `li[data-kind="perk-…"]`, текст в `PERK_TEXT`.
- **Цель:** запись в `GOALS` (`core.js`). Цели «миллион без …» считаются по снимку `s.won`.
- **Сет:** запись в `SETS` (`core.js`). Шансы пересчитаются сами.
- **Товар магазина:** запись в `STORE` (`core.js`): `shelf` из `STORE_SHELVES`, `name`, `note` (что даёт одной фразой), `once`; для темы ещё `theme` и блок `html[data-theme="…"]` в `style.css` (только цвета). Цену не хранить: её отдаёт `Pay.price`. Силу не продавать. Подробно — раздел «Магазин» в `docs/DESIGN.md`.

## Как устроены тесты

- Тесты входят в игру через меню, как игрок (`#menuPlay`).
- Отладочные ручки в странице: `window.z2m.state()`, `.refresh()`, `.skip(n)`, `.adMs` (длина заглушки рекламы).
- Барабаны подкладываются очередью значений `Math.random`. Для стартовой колоды с фокусом на работе: работа до .444, учёба до .556, здоровье до .667, связи до .741, шанс до .852, дальше счета. Перед такими шагами тест сбрасывает колоду (`fix()` в `tests/e2e.js`).
- Множитель и выбор развилки берут случайность уже после остановки барабанов: подкладывай их отдельной очередью после первого нажатия «Крутить».

## Что известно и не сделано

- Реклама — заглушка с таймером на 5 секунд. SDK нет.
- Оплата магазина — заглушка (`Pay` в `ui.js`): окно «Тестовая покупка», деньги не списываются, «Восстановить покупки» ничего не находит. Площадка не выбрана, SDK нет.
- Живого плейтеста не было: баланс проверен только ботами (`tools/sim.js`).
- Safari и настоящие телефоны не проверялись, только Chromium.
- Звук есть (WebAudio), но его никто не слушал.
- Автоспин включён по умолчанию: это осознанное решение автора.
- Частота рекламы не ограничена: на скорости ×1 «Удачный год» доступен примерно раз в минуту.
